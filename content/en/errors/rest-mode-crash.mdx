## What it means

Users report freezes and crashes around rest mode with a jailbreak loaded, for example in the WebKit Autoloader feedback thread for the 0.6 series. This is not confirmed for every console or firmware. The official etaHEN release notes describe rest mode fixes and a rest mode options menu meant to make rest mode more stable.

## What to do

<Step n={1} title="Check your build's rest mode options" src="etahen-releases">

etaHEN has rest mode settings: a delay, options to close games and apps for rest mode, and an option to turn off the Toolbox auto start. One older release note says the Toolbox auto start had to be turned off before entering rest mode.

</Step>

<Step n={2} title="As a check, close the game and test with fewer services">

Close the game before rest mode, and try again with fewer payloads and services running.

</Step>

## When to stop

<Warn kind="terms" title="Rest mode may not be stable">

There is no guarantee of a stable rest mode for every mix of firmware, HEN and mounting tool. If the problem continues, turn the console fully off instead of using rest mode until the cause is clear.

</Warn>
