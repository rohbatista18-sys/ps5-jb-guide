## What it means

This is about the cheats feature of the unofficial etaHEN port for 11.00 to 13.60. Its release notes document a fix in how it finds the running game: in an earlier 13.60 build, that lookup failed, so a cheat stopped before any change was applied.

## What to do

<Step n={1} title="Check support, Title ID and game version" src="etahen-port-releases">

The port's notes say the Title ID and version in the cheat file must match the running game exactly. A cheat made for another update of the game will not fit.

</Step>

<Step n={2} title="Check that your build includes the fix" src="etahen-port-releases">

Read the release notes of the build you use and look for the fix for finding the running game.

</Step>

## When to stop

<Warn kind="terms" title="The fix belongs to that port">

This fix is part of that unofficial port only. It is not a promise that every plugin or every game will work.

</Warn>
