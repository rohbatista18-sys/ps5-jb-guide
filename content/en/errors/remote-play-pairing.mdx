## What it means

The onionHEN README describes how to pair the official Remote Play app with a jailbroken console from the onionHEN Toolbox. This page covers only that pairing. The README does not mention PS Portal, so this page does not cover it either.

## What to do

<Step n={1} title="Make sure the account is activated" src="onionhen-readme">

The README says the current account must already be activated. If it is not, onionHEN blocks the Remote Play page and sends you to Toolbox → Account → Account activation.

</Step>

<Step n={2} title="Open Toolbox → Network → Remote Play" src="onionhen-readme">

The README says onionHEN then turns on the Remote Play setting and shows a pairing PIN.

</Step>

<Step n={3} title="Enter the PIN in the official Remote Play app while the page is open" src="onionhen-readme">

onionHEN uses the console's own Remote Play service to confirm the registered device.

</Step>

<Step n={4} title="Test at home first">

As a check, make sure a session works on your home network before you try to connect from somewhere else.

</Step>

## When to stop

<Warn kind="terms" title="Pairing only">

The README says this feature only handles pairing and registration. The video stream and the connection to the app are still handled by Sony's own Remote Play service. This guide has no confirmed information about PS Portal.

</Warn>
