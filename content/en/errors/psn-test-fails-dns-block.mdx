## What it means

For Y2JB, the README tells you to set the primary DNS to `127.0.0.2`, which keeps the PS5 from reaching PlayStation Network servers. It says that a network or PSN connection error may then appear, that this is expected, and that it can be safely ignored.

## What to do

<Step n={1} title="Check that you set the block on purpose" src="y2jb-readme">

If you set the DNS to `127.0.0.2` for Y2JB, or blocked PSN in your own DNS server, this error is expected. See the DNS step in the [Y2JB guide](/en/guias/y2jb-autoloader).

</Step>

## When to stop

<Warn kind="ban" title="This error alone is not a ban">

In this setup, a failed PSN test does not show that your console or account was banned. Do not remove the block just to make the PSN test pass.

</Warn>
