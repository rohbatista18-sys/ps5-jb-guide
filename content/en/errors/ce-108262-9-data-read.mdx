## What it means

Sony says an error occurred while reading the system software or the app's data.

## What to do

Sony's first suggestion is to install the latest system software. Skip it if you want to keep the jailbreak: see [the risks](/en/riscos).

<Step n={1} title="Delete the game or app and install it again" src="sony-ce-108262-9" />

<Step n={2} title="In Safe Mode, choose Clear Cache and Rebuild Database" src="sony-safemode-en">

Sony's Safe Mode page lists two options that delete all user data, and this is not one of them. Back up your saves anyway.

</Step>

## When to stop

<Warn kind="brick" title="Stop before any reset">

Sony's last resort is a full reset, which erases everything on the console. Back up your saves before you consider it.

</Warn>
