## What it means

The Y2JB README warns that letting YouTube update can cause a softlock: the app stops launching. It says this usually happens when the console connects to the internet before the DNS block is set up. The README has a section that explains how to recover.

## What to do

<Step n={1} title="Follow the softlock recovery section of the Y2JB README, in order" src="y2jb-readme">

Part of the recovery has you connect to the internet without the custom DNS for a while, so the console can reach Sony's servers during those steps.

</Step>

<Step n={2} title="Decline the system software update when it appears" src="y2jb-readme">

The recovery tells you to deny the system software update popup when you open YouTube again.

</Step>

<Step n={3} title="Set up the update block again, as the project describes" src="y2jb-readme">

The last steps put the DNS back and set up the YouTube update block again. The [Y2JB guide](/en/guias/y2jb-autoloader) on this site shows the DNS setting.

</Step>

## When to stop

<Warn kind="update" title="Never update the firmware to get YouTube back">

Do not accept a system software update as a way to unlock the app. A firmware update can leave you without a jailbreak.

</Warn>
