## What it means

Sony says an error occurred with the game or application.

## What to do

<Step n={1} title="Update the game" src="sony-ce-108255-1">

Sony suggests updating the game. If the console then asks you to update the system software, say no.

</Step>

## When to stop

<Warn kind="update" title="Do not update the system to fix a game">

If the only way left is a system software update, stop. Updating can close the jailbreak for good: see [the risks](/en/riscos).

</Warn>
