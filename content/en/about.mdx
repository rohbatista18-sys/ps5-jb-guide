<h2 id="about-title">About this website</h2>

PS5 JB Guide teaches beginners how to jailbreak **their own** PS5, run homebrew and back up **their own** games and saves.

This website was born in the [r/PS5_Jailbreak](https://www.reddit.com/r/PS5_Jailbreak/) community on Reddit. Visit it for news and help.

The website is open source: the code is [on GitHub](https://github.com/rohbatista18-sys/ps5-jb-guide).

- **What we never do:** link to or explain how to get pirated games, list "free jailbreak" sites, untested executables or donation scams.
- **Verified repositories only:** every repository is checked against the GitHub API and reviewed by a person before it appears here.
- **Sources for every claim:** <strong>proven</strong> means a primary source (the project's own README or release notes, or Sony's support pages); <strong>reported</strong> means news, forums or videos.
- **Privacy:** no accounts, analytics or tracking. The only cookie stores your language.
