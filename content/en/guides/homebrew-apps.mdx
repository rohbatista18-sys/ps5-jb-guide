## What are homebrew apps?

Homebrew apps are software made by independent developers that run on a jailbroken PS5. They can add features the console does not have by default, like file managers, FTP servers, media players and system utilities.

## Where to find them

Only use apps from repositories that have been reviewed on this guide's [verified repositories](/en/fw/7.00-13.60) list. Each repository links to its official GitHub page where you can download the latest release.

## Common types of homebrew

- **File managers** — browse and manage files on the console's storage.
- **FTP servers** — transfer files between the PS5 and a computer over your local network. See the [FTP guide](/en/guias/ftp-setup).
- **Package installers** — install PKG files. See the [PKG guide](/en/guias/install-packages).
- **System utilities** — tools for debugging, dumping firmware keys, or managing settings.
- **Media players** — play video and audio formats the PS5 does not support natively.

<Warn kind="scam" title="Verify before installing">

Never install an app just because someone recommended it in a forum or video. Check its source code on GitHub, read the issues, and look at the commit history. If the repository has no source code, do not install it.

</Warn>
