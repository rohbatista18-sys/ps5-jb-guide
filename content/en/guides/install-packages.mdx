<Warn kind="update" title="Jailbreak required">

You need an active jailbreak and HEN (Homebrew Enabler) running before you can install PKG files. Follow the [jailbreak tutorial](/en/fw/7.00-13.60) first.

</Warn>

## What is a PKG file?

A PKG file is the standard package format used by the PS5 to install applications. Homebrew apps, utilities and tools are distributed as PKG files.

## How to install

<Step n={1} title="Get the PKG file">

Download the PKG file from the official GitHub repository of the homebrew app you want. Never download PKG files from unverified sources.

</Step>

<Step n={2} title="Transfer the PKG to a USB drive">

Copy the PKG file to the root of a USB drive formatted as exFAT. The PS5 does not read NTFS.

</Step>

<Step n={3} title="Install from the USB drive">

With the jailbreak and HEN active, plug the USB drive into the PS5. The package installer should detect it automatically. Select the PKG file and install it.

</Step>

<Step n={4} title="Launch the app">

Once installed, the app appears on the home screen like any other game or application. It only works while the jailbreak is active for the current session.

</Step>

<Warn kind="brick" title="Only install PKGs from trusted sources">

A malicious PKG can damage your console's file system. Only install packages from repositories listed on this guide or that you have personally reviewed on GitHub.

</Warn>
