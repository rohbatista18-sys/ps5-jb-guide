<h2 id="about-title">Sobre este sitio web</h2>

PS5 JB Guide enseña a principiantes a hacer jailbreak de **su propia** PS5, ejecutar homebrew y hacer copias de seguridad de **sus propios** juegos y partidas guardadas.

Este sitio web nació en la comunidad [r/PS5_Jailbreak](https://www.reddit.com/r/PS5_Jailbreak/) de Reddit. Visítala para novedades y ayuda.

El sitio web es de código abierto: el código está [en GitHub](https://github.com/rohbatista18-sys/ps5-jb-guide).

- **Lo que nunca hacemos:** enlazar o explicar cómo conseguir juegos piratas, listar sitios de "jailbreak gratis", ejecutables sin probar o estafas de donaciones.
- **Solo repositorios verificados:** cada repositorio se comprueba en la API de GitHub y lo revisa una persona antes de aparecer aquí.
- **Fuentes para cada afirmación:** <strong>comprobado</strong> significa una fuente primaria (el README o las notas de versión del propio proyecto, o las páginas de soporte de Sony); <strong>reportado</strong> significa noticias, foros o videos.
- **Privacidad:** sin cuentas, analíticas ni rastreo. La única cookie guarda tu idioma.
