## Qué significa

Y2JB necesita una versión concreta de la app de YouTube, y la versión correcta depende de tu firmware. El README de Y2JB indica una versión de YouTube para firmware hasta 12.40 y otra para 12.60 en adelante. La página de releases de Y2JB hace lo mismo con los archivos de copia de seguridad: uno para 4.03 a 12.40 y otro para 12.60 en adelante. Si la app o la copia no corresponden a tu firmware, la configuración puede no arrancar.

Esto se aplica al proyecto Y2JB original.

## Qué hacer

<Step n={1} title="Compara tu firmware con el rango de la copia en la página de releases" src="y2jb-releases">

Cada archivo de copia de seguridad aparece en la página de releases con un rango de firmware. Usa solo el que cubre tu firmware.

</Step>

<Step n={2} title="Comprueba en el README la versión de YouTube para tu firmware" src="y2jb-readme">

El README indica una versión de YouTube para hasta 12.40 y otra para 12.60 en adelante. No mezcles archivos de los dos rangos.

</Step>

## Cuándo parar

<Warn kind="brick" title="Restaurar una copia borra la consola">

Restaurar la copia de seguridad de Y2JB cambia los datos de tu consola. El README de Y2JB avisa que la restauración devuelve la PS5 a los ajustes de fábrica y borra todos sus datos. Lee el procedimiento de restauración completo antes de empezar y haz antes una copia de tus partidas guardadas.

</Warn>
