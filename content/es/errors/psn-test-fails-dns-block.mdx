## Qué significa

Para Y2JB, el README indica poner el DNS primario en `127.0.0.2`, lo que impide que la PS5 llegue a los servidores de PlayStation Network. Dice que después puede aparecer un error de conexión a la red o a PSN, que es esperado y que se puede ignorar sin problema.

## Qué hacer

<Step n={1} title="Comprueba que configuraste el bloqueo a propósito" src="y2jb-readme">

Si pusiste el DNS en `127.0.0.2` para Y2JB, o bloqueaste PSN en tu propio servidor DNS, este error es esperado. Mira el paso del DNS en la [guía de Y2JB](/es/guias/y2jb-autoloader).

</Step>

## Cuándo parar

<Warn kind="ban" title="Este error por sí solo no es un baneo">

Con esta configuración, que falle la prueba de PSN no demuestra que tu consola o tu cuenta estén baneadas. No quites el bloqueo solo para que la prueba de PSN pase.

</Warn>
