## Qué significa

Y2JB abre en la consola un servidor (Remote JS Server) que recibe lo que envías. El README de Y2JB dice que este servidor no siempre usa el puerto `50000`: normalmente sí, pero a veces puede usar otro, y eso es normal.

## Qué hacer

<Step n={1} title="No des por hecho el puerto 50000" src="y2jb-readme">

Si la ejecución actual muestra un puerto, envía a ese.

</Step>

<Step n={2} title="Como comprobación, confirma la IP y la etapa">

Asegúrate de que envías a la IP actual de la consola y al servicio correcto para esta etapa. El servidor de JavaScript y el cargador ELF son servicios distintos.

</Step>

## Cuándo parar

<Warn kind="terms" title="Puertos de otros tutoriales">

Un puerto usado en otro tutorial puede no coincidir con tu ejecución actual.

</Warn>
