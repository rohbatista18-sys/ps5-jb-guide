## Qué significa

El README de onionHEN describe cómo vincular la aplicación oficial de Remote Play con una consola con jailbreak, desde la Toolbox de onionHEN. Esta página trata solo de esa vinculación. El README no menciona PS Portal, así que esta página tampoco.

## Qué hacer

<Step n={1} title="Comprueba que la cuenta esté activada" src="onionhen-readme">

El README dice que la cuenta actual ya debe estar activada. Si no lo está, onionHEN bloquea la página de Remote Play y te lleva a Toolbox → Account → Account activation.

</Step>

<Step n={2} title="Abre Toolbox → Network → Remote Play" src="onionhen-readme">

El README dice que onionHEN entonces activa el ajuste de Remote Play y muestra un PIN de vinculación.

</Step>

<Step n={3} title="Escribe el PIN en la aplicación oficial de Remote Play con la página abierta" src="onionhen-readme">

onionHEN usa el propio servicio de Remote Play de la consola para confirmar el dispositivo registrado.

</Step>

<Step n={4} title="Prueba primero en casa">

Como comprobación, asegúrate de que una sesión funcione en tu red de casa antes de intentar conectarte desde otro lugar.

</Step>

## Cuándo parar

<Warn kind="terms" title="Solo vinculación">

El README dice que esta función solo hace la vinculación y el registro. El vídeo y la conexión con la aplicación siguen a cargo del propio servicio de Remote Play de Sony. Esta guía no tiene información confirmada sobre PS Portal.

</Warn>
