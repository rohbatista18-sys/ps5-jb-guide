## Qué significa

El README de Y2JB avisa que dejar que YouTube se actualice puede causar un bloqueo (softlock): la app deja de abrirse. Dice que esto suele pasar cuando la consola se conecta a internet antes de configurar el bloqueo por DNS. El README tiene una sección que explica cómo recuperarse.

## Qué hacer

<Step n={1} title="Sigue en orden la sección de recuperación de softlock del README de Y2JB" src="y2jb-readme">

Una parte de la recuperación te pide conectarte a internet sin el DNS personalizado durante un rato, así que en esos pasos la consola puede llegar a los servidores de Sony.

</Step>

<Step n={2} title="Rechaza la actualización del software del sistema cuando aparezca" src="y2jb-readme">

La recuperación indica que rechaces el aviso de actualización del software del sistema al volver a abrir YouTube.

</Step>

<Step n={3} title="Vuelve a configurar el bloqueo de actualizaciones como indica el proyecto" src="y2jb-readme">

Los últimos pasos vuelven a poner el DNS y a configurar el bloqueo de actualizaciones de YouTube. La [guía de Y2JB](/es/guias/y2jb-autoloader) de este sitio muestra el ajuste de DNS.

</Step>

## Cuándo parar

<Warn kind="update" title="Nunca actualices el firmware para recuperar YouTube">

No aceptes una actualización del software del sistema como forma de desbloquear la app. Una actualización de firmware puede dejarte sin jailbreak.

</Warn>
