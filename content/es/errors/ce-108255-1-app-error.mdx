## Qué significa

Sony dice que se produjo un error con el juego o la aplicación.

## Qué hacer

<Step n={1} title="Actualiza el juego" src="sony-ce-108255-1">

Sony sugiere actualizar el juego. Si después la consola te pide actualizar el software del sistema, di que no.

</Step>

## Cuándo parar

<Warn kind="update" title="No actualices el sistema para arreglar un juego">

Si la única salida es actualizar el software del sistema, para. Actualizar puede cerrar el jailbreak para siempre: mira [los riesgos](/es/riscos).

</Warn>
