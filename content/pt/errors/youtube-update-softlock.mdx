## O que significa

O README do Y2JB avisa que deixar o YouTube atualizar pode causar um travamento (softlock): o aplicativo deixa de abrir. Ele diz que isso costuma acontecer quando o console se conecta à internet antes de o bloqueio por DNS estar configurado. O README tem uma seção que explica como recuperar.

## O que fazer

<Step n={1} title="Siga em ordem a seção de recuperação de softlock do README do Y2JB" src="y2jb-readme">

Uma parte da recuperação pede que você se conecte à internet sem o DNS personalizado por um tempo, então nesses passos o console pode alcançar os servidores da Sony.

</Step>

<Step n={2} title="Recuse a atualização do software do sistema quando ela aparecer" src="y2jb-readme">

A recuperação manda recusar o aviso de atualização do software do sistema ao abrir o YouTube de novo.

</Step>

<Step n={3} title="Refaça o bloqueio de atualizações conforme o projeto" src="y2jb-readme">

Os últimos passos recolocam o DNS e refazem o bloqueio de atualizações do YouTube. O [guia do Y2JB](/pt/guias/y2jb-autoloader) deste site mostra a configuração do DNS.

</Step>

## Quando parar

<Warn kind="update" title="Nunca atualize o firmware para recuperar o YouTube">

Não aceite atualizar o software do sistema como tentativa de destravar o aplicativo. Uma atualização de firmware pode deixar você sem jailbreak.

</Warn>
