## O que significa

O README do onionHEN descreve como parear o aplicativo oficial do Remote Play com um console com jailbreak, pela Toolbox do onionHEN. Esta página trata só desse pareamento. O README não fala do PS Portal, então esta página também não.

## O que fazer

<Step n={1} title="Confira se a conta está ativada" src="onionhen-readme">

O README diz que a conta atual precisa já estar ativada. Se não estiver, o onionHEN bloqueia a página do Remote Play e manda você para Toolbox → Account → Account activation.

</Step>

<Step n={2} title="Abra Toolbox → Network → Remote Play" src="onionhen-readme">

O README diz que o onionHEN então liga a configuração do Remote Play e mostra um PIN de pareamento.

</Step>

<Step n={3} title="Digite o PIN no aplicativo oficial do Remote Play com a página aberta" src="onionhen-readme">

O onionHEN usa o próprio serviço de Remote Play do console para confirmar o dispositivo registrado.

</Step>

<Step n={4} title="Teste primeiro em casa">

Como diagnóstico, confira se uma sessão funciona na sua rede de casa antes de tentar se conectar de outro lugar.

</Step>

## Quando parar

<Warn kind="terms" title="Só pareamento">

O README diz que esse recurso só faz o pareamento e o registro. O vídeo e a conexão com o aplicativo continuam por conta do serviço de Remote Play da própria Sony. Este guia não tem informação confirmada sobre o PS Portal.

</Warn>
