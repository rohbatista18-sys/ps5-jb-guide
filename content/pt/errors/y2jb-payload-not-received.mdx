## O que significa

O Y2JB abre no console um servidor (Remote JS Server) que recebe o que você envia. O README do Y2JB diz que esse servidor nem sempre usa a porta `50000`: normalmente usa, mas às vezes pode usar outra, e isso é normal.

## O que fazer

<Step n={1} title="Não suponha que a porta é 50000" src="y2jb-readme">

Se a execução atual mostrar uma porta, envie para ela.

</Step>

<Step n={2} title="Como diagnóstico, confirme o IP e a etapa">

Confira se você está enviando para o IP atual do console e para o serviço certo nesta etapa. O servidor de JavaScript e o loader ELF são serviços diferentes.

</Step>

## Quando parar

<Warn kind="terms" title="Portas de outros tutoriais">

Uma porta usada em outro tutorial pode não corresponder à execução atual.

</Warn>
