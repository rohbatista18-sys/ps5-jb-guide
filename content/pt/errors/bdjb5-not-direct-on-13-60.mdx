## O que significa

O BD-JB5 é uma entrada de jailbreak que roda a partir de um disco Blu-ray. O README dele diz que o suporte vai até o firmware 13.42. No 13.60, o procedimento com o disco que você pode ter usado em um firmware anterior não funciona sozinho.

## O que fazer

<Step n={1} title="Confira se o seu firmware está na faixa suportada" src="bdjb5-readme">

O README indica suporte direto até o 13.42.

</Step>

<Step n={2} title="No 13.60, o console já precisa estar desbloqueado" src="bdjb5-readme">

Para o 13.60, o README descreve enviar o `bdj_unpatch.elf` ao ELF loader para desfazer o patch do BD-J e só depois usar o BD-JB. Esse passo exige um PS5 que já foi desbloqueado por outra cadeia.

</Step>

## Quando parar

<Warn kind="terms" title="Não é a primeira entrada no 13.60">

O passo do `bdj_unpatch` não é uma entrada independente para um PS5 13.60 que ainda está bloqueado. Sem outro jailbreak funcionando nesse console, o BD-JB5 sozinho não resolve.

</Warn>
