## O que significa

A Sony diz que, se a luz de energia só pisca em branco ou fica azul, o console travou. Isso também pode acontecer durante uma tentativa de jailbreak: o README do Relapse avisa que o console pode travar e manda reiniciar antes de tentar de novo.

## Quando parar

<Warn kind="brick" title="Não parta direto para a reinstalação">

Se continuar acontecendo, o próximo passo da Sony é reinstalar o software do sistema no Modo de Segurança. A Sony diz que isso apaga todos os dados do usuário e remove o software do sistema, então você pode perder a versão de que o jailbreak precisa. Faça backup dos saves antes, e só faça isso se precisar do console funcionando mais do que do jailbreak.

Se o console travar quando você não está tentando o jailbreak, pare de usar o jailbreak até entender o motivo.

</Warn>
