## O que significa

O Y2JB precisa de uma versão específica do aplicativo do YouTube, e a versão certa depende do seu firmware. O README do Y2JB indica uma versão do YouTube para firmware até 12.40 e outra para 12.60 em diante. A página de releases do Y2JB faz o mesmo com os arquivos de backup: um para 4.03 a 12.40 e outro para 12.60 em diante. Se o aplicativo ou o backup não corresponder ao seu firmware, a configuração pode não iniciar.

Isso vale para o projeto Y2JB original.

## O que fazer

<Step n={1} title="Compare seu firmware com a faixa do backup na página de releases" src="y2jb-releases">

Cada arquivo de backup aparece na página de releases com uma faixa de firmware. Use só o que cobre o seu firmware.

</Step>

<Step n={2} title="Confira no README a versão do YouTube para o seu firmware" src="y2jb-readme">

O README indica uma versão do YouTube para até 12.40 e outra para 12.60 em diante. Não misture arquivos das duas faixas.

</Step>

## Quando parar

<Warn kind="brick" title="Restaurar um backup apaga o console">

Restaurar o backup do Y2JB altera os dados do seu console. O README do Y2JB avisa que a restauração volta o PS5 às configurações de fábrica e apaga todos os dados dele. Leia o procedimento de restauração inteiro antes de começar e faça backup dos seus saves antes.

</Warn>
