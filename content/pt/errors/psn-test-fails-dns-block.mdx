## O que significa

Para o Y2JB, o README manda colocar o DNS primário em `127.0.0.2`, o que impede o PS5 de alcançar os servidores da PlayStation Network. Ele diz que depois disso pode aparecer um erro de conexão com a rede ou com a PSN, que isso é esperado e que pode ser ignorado com segurança.

## O que fazer

<Step n={1} title="Confira se o bloqueio foi intencional" src="y2jb-readme">

Se você colocou o DNS em `127.0.0.2` para o Y2JB, ou bloqueou a PSN no seu próprio servidor DNS, esse erro é esperado. Veja o passo do DNS no [guia do Y2JB](/pt/guias/y2jb-autoloader).

</Step>

## Quando parar

<Warn kind="ban" title="Esse erro sozinho não é banimento">

Nessa configuração, a falha no teste de PSN não comprova que o console ou a conta foram banidos. Não remova o bloqueio só para fazer o teste de PSN passar.

</Warn>
