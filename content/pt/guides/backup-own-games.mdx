## Por que fazer backup dos seus jogos?

- Preservar os seus jogos de disco como cópias digitais para não precisar do disco toda vez.
- Manter uma cópia caso um disco risque ou danifique.
- Guardar jogos num HD externo para acesso mais rápido.

## Como fazer backup de um jogo de disco

<Step n={1} title="Insira o disco">

Coloque o disco do jogo no PS5. Não inicie o jogo.

</Step>

<Step n={2} title="Use uma ferramenta de dump">

Com o jailbreak e o HEN ativos, rode um app homebrew de dump de disco. Ele lê o disco e salva uma cópia no armazenamento interno do console ou num pendrive.

</Step>

<Step n={3} title="Transfira o backup">

Use [FTP](/pt/guias/ftp-setup) ou um pendrive para mover o backup para o computador ou armazenamento externo.

</Step>

<Step n={4} title="Instale o backup">

O backup é um arquivo PKG. Instale como qualquer outro PKG — veja [como instalar arquivos PKG](/pt/guias/install-packages).

</Step>

<Warn kind="ban" title="Não compartilhe os seus backups">

Compartilhar os seus backups de jogos com outras pessoas é pirataria. Este guia existe para ajudar você a preservar a sua própria biblioteca, não para distribuir jogos.

</Warn>
