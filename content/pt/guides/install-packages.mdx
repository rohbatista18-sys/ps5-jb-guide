Você precisa de um jailbreak ativo e do HEN (Homebrew Enabler) rodando antes de instalar arquivos PKG. Siga o [tutorial de jailbreak](/pt/fw/7.00-13.60) primeiro.

</Warn>

## O que é um arquivo PKG?

Um arquivo PKG é o formato padrão de pacote usado pelo PS5 para instalar aplicativos. Apps homebrew, utilitários e ferramentas são distribuídos como arquivos PKG.

## Como instalar

<Step n={1} title="Baixe o arquivo PKG">

Baixe o arquivo PKG do repositório oficial no GitHub do app homebrew que você quer. Nunca baixe arquivos PKG de fontes não verificadas.

</Step>

<Step n={2} title="Transfira o PKG para um pendrive">

Copie o arquivo PKG para a raiz de um pendrive formatado em exFAT. O PS5 não lê NTFS.

</Step>

<Step n={3} title="Instale pelo pendrive">

Com o jailbreak e o HEN ativos, conecte o pendrive ao PS5. O instalador de pacotes deve detectá-lo automaticamente. Selecione o arquivo PKG e instale.

</Step>

<Step n={4} title="Abra o app">

Depois de instalado, o app aparece na tela inicial como qualquer outro jogo ou aplicativo. Ele só funciona enquanto o jailbreak estiver ativo na sessão atual.

</Step>

<Warn kind="brick" title="Só instale PKGs de fontes confiáveis">

Um PKG malicioso pode danificar o sistema de arquivos do console. Só instale pacotes de repositórios listados neste guia ou que você tenha revisado pessoalmente no GitHub.

</Warn>
