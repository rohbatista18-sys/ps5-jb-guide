<h2 id="about-title">Sobre este site</h2>

O PS5 JB Guide ensina iniciantes a fazer o jailbreak do **próprio** PS5, rodar homebrew e fazer backup dos **próprios** jogos e saves.

Este site nasceu na comunidade [r/PS5_Jailbreak](https://www.reddit.com/r/PS5_Jailbreak/) do Reddit. Acesse para novidades e ajuda.

O site tem código aberto: o código está [no GitHub](https://github.com/rohbatista18-sys/ps5-jb-guide).

- **O que nunca fazemos:** linkar ou explicar como obter jogos piratas, listar sites de "jailbreak grátis", executáveis não testados ou golpes de doação.
- **Só repositórios verificados:** cada repositório é conferido na API do GitHub e revisado por uma pessoa antes de aparecer aqui.
- **Fonte para cada afirmação:** <strong>comprovado</strong> significa uma fonte primária (o README ou as release notes do próprio projeto, ou as páginas de suporte da Sony); <strong>relatado</strong> significa notícia, fórum ou vídeo.
- **Privacidade:** sem contas, analytics ou rastreamento. O único cookie guarda o seu idioma.
